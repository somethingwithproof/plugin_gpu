<a id="performance-and-scale"></a>
# الأداء والحجم

قياسات للقضية #49 (REQ-PERF-001 إلى REQ-PERF-004) باستخدام `tests/bin/scale-flow.php`. مصدرها محطة تطوير واحدة لا أجهزة إنتاج. اقرأها حدًا أعلى لكلفة الإضافة، لا سعة مدعومة؛ فخادم Cacti الإنتاجي وقاعدته وشبكته إلى العقد الحقيقية تختلف.

<a id="machine"></a>
## الجهاز

| البند | القيمة |
|---|---|
| المضيف | Apple M3 Max، 14 نواة، ذاكرة 36 GiB |
| بيئة الحاويات | OrbStack (Docker 29.8.2)، 14 وحدة CPU و15.7 GiB لآلتها الافتراضية |
| Cacti | الإصدار 1.2.31 وفرع 1.2.x، PHP 8.2، وMariaDB في حاوية على المضيف نفسه |
| وكيل العقدة | وكيل net-snmp `snmpd` حقيقي واحد في حاوية عبر SNMPv3 يخدم كل العقد؛ يطبع `nvidia-smi` الوهمي بيانات اختبار ثماني وحدات GPU |

تشترك العقد كلها في وكيل واحد على المضيف نفسه، لذا يقترب تأخر الشبكة من الصفر وتُحسب كلفة الوكيل لكل عقدة مرة لكل قراءة. تضيف البيئة الحقيقية رحلة شبكة ذهابًا وإيابًا لكل طلب SNMP وكلفة `nvidia-smi` على كل عقدة (#25).

<a id="method"></a>
## الطريقة

يسجل الاختبار `<gpus> / 8` جهاز Cacti، كل منها عقدة GPU على الوكيل نفسه. يغلّف قارئ اختبار قارئ SNMP extend ويعيد كتابة UUID بمعرّف الجهاز كي تبلغ كل عقدة عن وحداتها؛ وتبقى كل قراءة تبادل SNMPv3 حقيقيًا. يقيس جولتي جمع، الأولى تسجل الوحدات والثانية في حالة مستقرة، ومدخل خادم السكربتات باستدعاء index لكل عقدة وget لكل عنصر مصدر كما يفعل مستطلِع Cacti، وعرض GPU Health مع التأكد من عدم إرساله حزم SNMP. ومع `provision` ينشئ أيضًا كائنات Cacti عبر مُجهّز الإضافة، ويشغّل دورة استطلاع، ويتحقق من إيقاف الميزانية الزمنية الجولة مبكرًا وعدّ العقد المتخطاة.

<a id="results"></a>
## النتائج

لم تُسجل بعد. تشغّل CI حالة 100 وحدة GPU مع كائنات Cacti في كل مهمة بالمصفوفة. ستُسجل هنا تجربة 1,000 وحدة مع الكائنات وتجربة جمع 8,000 وحدة على هذا الجهاز بعد تنفيذها، مع أعداد الصفوف. حتى ذلك الحين تبقى REQ-PERF-001 مفتوحة ولا تعلن الإضافة عدد GPU مدعومًا.

<a id="what-this-supports"></a>
## ما تدعمه هذه النتائج

لا شيء بعد. حسابات الخطة لـ 1,000 عقدة تضم كل منها ثماني وحدات GPU موجودة في [PLAN.md](../../../PLAN.md#performance). لا يُعلن عدد مدعوم إلا بعد قياسه هنا وتأكيده على أجهزة بحجم إنتاجي.

<a id="not-measured"></a>
## ما لم يُقَس

- الكلفة الحقيقية لـ `nvidia-smi` على العقدة وأقل فاصل ممكن (#25).
- قاعدة بيانات بعيدة وخادم Cacti إنتاجي وتأخر الشبكة إلى العقد.
- صفحات Cacti للأجهزة ومصادر البيانات والرسوم عند 8,000 وحدة GPU (REQ-PERF-004)؛ لم تُنشأ كائنات Cacti في تجربة 8,000 وحدة.
